# 장면 기법 목록

`/promo` 2단계에서 기능마다 1순위 · 예비 기법을 고를 때 쓴다. 먼저 표로 훑고, 고른 기법만 본문을 읽는다.

출처: video-shotcraft `references/shots/` 카드 124장 중 HTML(CSS transform · opacity · filter · clip-path · mask, SVG, Canvas 2D)로 만들 수 있는 27개 (Apache-2.0). Remotion `spring` · `Easing`은 `renderAt(frame)` 안의 순수 함수로 직접 구현한다. 원문 카드 대부분이 "자리표시 소재로 맞춘 출발값"이라고 적어 두었으므로, 수치는 출발점이고 확인 프레임으로 조정한다. 다만 "함정"은 낮추지 않는다. 더 자세한 값이 필요하면 원본 카드 경로를 연다.

f 는 30fps 기준 프레임. 3D(WebGL) · 원근 카메라가 필수인 카드, 특정 앱 전용, 원작자 브랜드 의존 카드는 뺐다.

## 오프닝

### `text-as-mask`
굵은 글자 모양의 창 안에서 제품 화면이 흐르다가, 글자가 부풀며 화면 전체를 넘겨받는다.
- 만드는 법: SVG 글자(흰 글자 · 검은 바탕)를 data-URI 로 CSS `mask-image`에 넣어 제품 레이어를 감싼다. 18~96f 글자는 고정, 안쪽만 scale 1.32 · translateX +150→−150px. 96~104f 글자 1→0.965 로 숨 들이쉬기. 104~128f `S = s0·(46/s0)^(t^1.8)`로 46배 확대, 기준점은 획 안쪽, 내용 레이어는 1/S 로 역보정. 글자 470px · 굵기 900 (Windows 는 웹폰트 900 권장).
- 함정: 마스크와 내용의 transform 을 한 요소에 합치면 제품 화면까지 수십 배로 부푼다.
- 원본: `opening/text-as-mask.md`

## 글자

### `blur-slide`
단어마다 흐림을 벗으며 아래에서 떠오르는 기본 제목 등장.
- 만드는 법: 단어별 진행값 p 하나(quint ease-out)에 opacity = p, y = (1−p)·64px(약 0.38em), blur = (1−p)·18px 을 묶는다. 주제목 단어 간격 4f · 단어당 22f, 부제는 2.4f · 20f · 26px · 9px 이고 주제목이 끝나기 전에 시작해 약 26f 겹친다.
- 함정: 세 속성에 곡선을 따로 주면 "자리는 왔는데 아직 흐림"이 생긴다. 한글은 `split(' ')` 대신 의미 단위 3~5조각으로 나눈다. 간격 2f 미만은 한 줄이 통째로, 8f 초과는 단어를 세게 된다.
- 원본: `typography/blur-slide.md`

### `pill-slot-cycle`
문장 앞부분은 두고, 끝의 알약 칸 단어만 슬롯처럼 바꾸다가 결론 단어로 닫는다.
- 만드는 법: 한 박 21f (앞 8f 교체 · 13f 정지). 새 단어 y 120→0 · blur 14→0 (cubic out), 옛 단어 y 0→−130 · blur →10 (cubic in). 결론 단어만 back(1.4) 로 14f 오버슈트, 완성 문장은 45f 이상 정지.
- 함정: 문장을 flex 가운데 정렬하면 알약 폭이 바뀔 때마다 흔들린다. 왼쪽 기준 절대 위치로 고정.
- 원본: `typography/pill-slot-cycle.md`

### `marker-underline`
제목이 자리 잡은 뒤 핵심 단어 밑에 손으로 그은 마커 밑줄이 한 번에 지나간다.
- 만드는 법: SVG path dashoffset 으로 왼→오 10f (ease-out). 붓 모양은 가운데 약 0.12em, 양 끝 0.6배. `feTurbulence` 변위 약 1.8px 로 가장자리를 거칠게. 글자 바닥 −0.1em, 제목 착지 후 4~8f 에 시작.
- 함정: 기울기를 글자 흐름과 반대로(왼쪽이 높게) 그으면 가짜로 보인다. 14f 를 넘기면 진행 막대처럼 읽힌다.
- 원본: `typography/marker-underline-title.md`

### `title-card`
기능 장면 사이에 한 문장을 도장처럼 찍어 숨 고르는 자막 카드.
- 만드는 법: i번째 단어는 4+4i f 에 시작해 9f 동안 scale 1.28→1 · blur 7→0 · opacity 증가 (`cubic-bezier(0.2,0.75,0.3,1)`). 강조 단어는 하나만 기울임 + 강조색. 16~34f 짧은 밑줄 scaleX 0→1, 마지막 8f 페이드아웃.
- 함정: 추상 비유 말고 기능 이름 + 구체적 효과. 마무리 문구와 겹치면 뺀다.
- 원본: `typography/paper-title-card.md`

### `retype`
평범한 말을 쳤다가 지우고, 진짜 장점을 더 빠르게 다시 친다.
- 만드는 법: 보이는 글자는 `substring(0, floor((f−시작)/스텝))` (보간 없음). 입력 2f/자 → 16f 멈춤(커서 두 번 깜박) → 삭제 1.5f/자 → 재입력 1.5f/자. 입력 · 삭제 중엔 커서를 켜 둔다. 끝에 50f 이상 정지.
- 함정: 세 속도 차이가 느껴지지 않으면 버그처럼 보인다. 한 편에 한 번. 한글은 조합 중간 글자를 보여 주지 말고 완성 글자 단위로.
- 원본: `typography/typewriter-moves.md`

### `lead-word-assemble`
첫 단어가 2.3배로 화면을 채운 뒤 제자리 크기로 줄고, 나머지 단어가 밀려 들어와 문장이 된다.
- 만드는 법: 0~12f 2.3 → 2.3×1.06 으로 더 다가옴, 12~24f 크기 1로, 12~36f 같은 곡선(`cubic-bezier(.5,0,.05,1)`)으로 가로 이동 (이동량 = 줄 폭 × (0.5 − 첫 단어 중심 비율)). 뒷단어는 18+4(i−1) f 에 시작해 12f 동안 0.5em→0, 투명도는 2f 만에. transform-origin = "첫 단어 중심 % + 기준선 px".
- 함정: 기준점을 박스 중앙에 두면 마지막 몇 프레임에 기준선이 떨린다. 폭을 재기 전 프레임은 opacity 0.
- 원본: `typography/lead-word-zoom-assemble.md`

## UI 등장

### `list-reveal`
메뉴 항목이 차례로 작은 크기에서 제자리를 잡고, 목록 전체는 천천히 위로 흐른다.
- 만드는 법: 항목 i 는 2+10i f 시작, 창 24f, scale 0.82→1 · y 44→0 · blur 8→0 (`cubic-bezier(0.3,1.18,0.5,1)`, 약 1.5% 오버슈트). 목록 전체는 처음부터 끝까지 96px(+48→−48) 올라간다.
- 함정: 마지막 프레임이 −48px 에서 끝나 제자리가 아니다. 다음 장면과 맞추려면 끝을 감속 곡선으로.
- 원본: `ui-entrance/list-reveal.md`

### `card-stack`
카드가 아래에서 점점 빠르게 튀어 올라 더미가 되고, 부채처럼 펼친 뒤 가운데 카드를 뽑는다.
- 만드는 법: 9장을 40f 안에 ease-out 분포로 출발, 스프링(감쇠 13 · 강성 150)으로 y 820→0. 착지마다 더미 전체 5px 눌림(9f). 68f 에 스프링(20/95)으로 펼침 (각도 k·6.5°, 가로 k·138px, origin `50% 130%`). 가운데 카드 72px 뽑기.
- 함정: 카드를 늘리면 등장이 펼치기 구간을 먹는다. 펼치기 시작도 같이 미룬다. 카드는 홀수 장.
- 원본: `ui-entrance/card-stack.md`

### `bento-light-up`
어두운 벤토 칸들을 빛 꼬리가 한 바퀴씩 돌며 차례로 켠다.
- 만드는 법: 20f 대기 후 12f 간격으로 켬. 칸 테두리 `rect pathLength=100` 을 8f 동안 그리며 둘레 22% 길이의 빛 꼬리를 앞세움. 테두리가 반쯤 돌았을 때(+6f) 내용이 opacity 0.18 · y 20px 에서 back-out 8f 로 올라옴. 다 켜지면 scale 1→1.04 로 25f.
- 함정: 어두운 바탕 전제. 밝은 바탕에서 0.18 로 어둡게 하면 고장처럼 보인다.
- 원본: `ui-entrance/wall-reveal-moves.md` (변형 A)

### `draw-trace`
펜 끝이 보이는 선이 카드 윤곽을 한 바퀴 그리고, 선이 닫히는 순간 내용이 채워진다.
- 만드는 법: `pathLength=1`, dashoffset 1→0 을 40f (inOut cubic). 같은 경로에 점점 가늘어지는 짧은 dash 3겹으로 펜 끝. 닫힐 때 2f 동안 진하게 · 두께 6→11px, 6f 에 되돌림. 그 뒤 내용이 3f 간격으로.
- 함정: 선의 rx 가 카드 radius 와 다르면 넘어가는 순간 모양이 어긋난다. 선이 닫히기 전에 내용이 나오면 안 된다.
- 원본: `ui-entrance/draw-svg-trace.md`

### `stack-press`
카드가 하나씩 올라와 쌓일 때마다 더미가 눌렸다 튀고, 숫자가 한 칸씩 굴러간다.
- 만드는 법: 12f 간격, 카드당 22f. 600px 아래에서 ±2° 번갈아 기울어진 채 scale 1.06→1 (`cubic-bezier(0.45,0.05,0.25,1.12)`). 착지 때 더미 [0,6,0]px 8f. 카운터는 0~9 숫자 띠 두 벌을 이어 8f 굴림, `tabular-nums`.
- 함정: 한 칸 굴리는 시간이 카드 간격(12f)보다 길면 마지막 숫자가 덜 굴러간 채 끝난다.
- 원본: `ui-entrance/list-stack-press.md`

## 카메라

### `crash-zoom`
전체 화면에서 6프레임 만에 목표로 들이박는 급줌.
- 만드는 법: zoom 1→2.6 을 6f ease-in, 중심점도 함께 목표로. 직전 6~8f 에 3~4% 물러섰다 들어감. 착지는 둘 중 하나: 5f 동안 3~6% 되튀기, 또는 흔들림 14px·e^(−t/1.8) 6f. 앞 30f 이상 · 뒤 45f 이상 정지.
- 함정: 두 착지 방식을 섞지 않는다. 확대 대상은 고해상도 캡처 필요(`craft.md` Q2). 10f 를 넘기면 그냥 줌인처럼 보인다. 흔들림 20px 초과는 고장처럼 보인다. 화면 전체 충격 횟수(R4)에 들어간다.
- 원본: `camera/crash-zoom-punch.md`

### `cursor-flyover`
전체를 내려다본 뒤 카메라가 네 영역을 차례로 돌고, 커서가 먼저 가서 클릭한다.
- 만드는 법: 2400×1500 월드에 `translate(960−x·s, 540−y·s) scale(s)`, 전체 s=0.66 · 근접 1.3. 이동 20f (`cubic-bezier(.55,0,.18,1)`, 이동 중 8% 줌아웃) + 머무름 24f. 커서는 카메라보다 2f 먼저 출발, 6f 먼저 도착. 클릭 때 커서 3f 0.84, 80px 물결 18f. 마지막 24f 전체 보기로.
- 함정: 커서 · 카메라 시차는 한 쌍으로 같이 바꾼다. 한쪽만 바꾸면 클릭 반응이 묻힌다.
- 원본: `camera/cursor-flyover.md`

### `depth-layers`
먼 층 · 가운데 층 · 가까운 층을 다른 속도로 가로 이동시켜 평면 캡처에 깊이를 준다.
- 만드는 법: 같은 이동량에 층별 0.35 / 0.7 / 1.4배, 제목 층은 고정. 먼 층 blur 5px · 채도 0.7, 가까운 층 blur 7px. 130f (`cubic-bezier(.45,0,.18,1)`), 주인공 카드가 중앙에 멈추도록 이동량을 역산. 멈춘 뒤 8f 늦게 주인공이 떠오름.
- 함정: 화면 전체 크기 레이어에 매 프레임 바뀌는 `filter: blur`를 걸면 렌더가 3배 이상 느려진다. 작은 요소에만.
- 원본: `camera/depth-layer-moves.md`

## 조작

### `type-and-filter`
검색창에 사람 속도로 입력하면 격자가 한 장으로 좁혀지고, 클릭하면 상세로 들어간다.
- 만드는 법: 3f/자 입력 (입력 중 커서 켬, 끝나면 8f 주기 깜박). 약 11f 쉬고, 나머지 카드는 0.4f 간격으로 5f 동안 흐려지며 8px 내려감. 목표 카드는 10f 동안 실제 첫 칸 자리로. 이중 물결(3f 차)로 클릭, 16f 동안 줌 2.2 로 들어간 뒤 흰 번쩍 컷.
- 함정: 첫 판은 거의 늘 너무 빠르다 (`craft.md` R3). 목표 카드가 실제 칸이 아니라 화면 중앙에 떠 있으면 가짜로 보인다 (Q9).
- 원본: `interaction/type-and-filter.md`

### `toggle-hero`
크게 키운 2단 토글을 커서가 누르면 thumb 이 미끄러지고 새 아이콘이 튀어나온다.
- 만드는 법: 1080×220 컨트롤이 아래 200px 에서 스프링(14/120)으로. 130px 커서가 24f 동안 들어옴. 누름 1→0.86→1 (3f+4f), 3px 물결 12f. thumb 8f cubic out, 같은 때 새 아이콘 스프링(10/220), 옛 아이콘 6f 동안 width 0.
- 함정: 옛 아이콘을 scale 로만 줄이면 빈자리가 남는다. width 도 0 으로. 3단 이상 토글엔 맞지 않는다.
- 원본: `interaction/segmented-thumb-hero.md`

## 효과

### `lock-on`
L자 모서리 넷이 화면 밖에서 날아와 목표를 물고 고정한다.
- 만드는 법: 네 모서리는 한 사각형의 대칭 4조각. 날아오기(1000px 이상, 10f cubic out)와 줄어들기(2.2×→0.94×→1)는 곡선을 따로. 무는 프레임에 목표 위 흰 덧칠(0.55→0.28)과 라벨 등장을 같은 프레임에.
- 함정: 한 편에 2번 이하, 두 번이면 목표가 달라야 한다.
- 원본: `effects/fui-hud-moves.md`

### `sheen-sweep`
어두운 주인공 카드 위로 비스듬한 빛줄기가 한 번 지나간다.
- 만드는 법: 카드 폭 2배의 빛 띠, 115° 그라디언트 (넓은 빛 0.14 + 좁은 심 0.5, `mix-blend-mode: screen`). 58~90f 에 한 번. 카드는 둥근 모서리 `overflow:hidden`으로 빛을 자르고 같은 구간에 `rotateY` 21°→14°. 지나가면 빛 레이어 제거.
- 함정: 흰 바탕에선 안 보인다. 빛 효과는 영상 전체 2번 이하 (`craft.md` Q4).
- 원본: `effects/light-play-moves.md`

## 데이터

### `before-after`
이전 · 이후 화면을 겹쳐 두고 분할 막대를 휙 넘긴 뒤 천천히 다시 훑는다.
- 만드는 법: 막대 위치 8% → (6.5% 로 살짝 당김) → 12f 만에 76% → 12f 에 70% → 약 18f 멈춤 → 약 48f 동안 40% → 40f 이상 정지. after 레이어는 `clip-path: inset()` 오른쪽 경계를 막대 x 에 묶음. 빠른 구간 : 느린 구간 ≈ 1:5.
- 함정: 두 화면의 배치 · 구도가 다르면 비교가 안 된다. before 를 일부러 못나게 만들지 않고 실제 이전 상태를 쓴다.
- 원본: `data/before-after-slider-scrub.md`

### `scroll-brake`
긴 목록이 색 띠처럼 고속으로 흐르다 급제동해 이번 항목에 멈춘다.
- 만드는 법: translateY 약 2400px 를 50f (`cubic-bezier(.45,0,.06,1)`). 세로 blur = 프레임 간 위치 차이 × 0.32 (최대 30px), 멈추면 0. 멈춘 행은 scale 1.03 · 그림자 · 2px 강조 테두리, 나머지 opacity 0.38. 행 높이 72/94/116 섞기.
- 함정: 멈추는 행은 실제 내용이어야 한다. 나머지 행을 0 까지 지우면 맥락이 사라진다.
- 원본: `data/scroll-brake-moves.md` (변형 A)

## 리듬

### `freeze-annotate`
흐르던 카드 줄이 갑자기 멈추고, 마커로 동그라미와 메모를 남긴 뒤 다시 흐른다.
- 만드는 법: 출력 프레임 → 원본 프레임을 비선형 매핑 (흐름 기울기 1, 정지 0, 재개는 smootherstep 22f). 멈추는 순간 흰 번쩍 3f · 네 모서리 표식 · 정지 표시. 마커 타원은 10f dashoffset (1.08바퀴, 끝은 닫지 않음), 화살표 6f+3f, `feTurbulence` scale 약 6 으로 손떨림.
- 함정: 정지 신호가 없으면 의도한 정지와 버벅임을 구분 못 한다. 30초 영상에 2번 이하.
- 원본: `rhythm/speed-ramp-freeze.md`

## 전환

이음매 하나에 전환 하나. 전환 프레임은 이웃 장면 예산에서 뺀다.

### `flash-cut` · `whip-pan`
흰 번쩍으로 컷을 덮거나, 빠른 가로 이동의 흐린 프레임 속에 컷을 숨긴다.
- 만드는 법: flash-cut 은 컷 프레임 −5f~+5f 에 흰 레이어 (장식으로 쓰지 않는다). whip-pan 은 출발 전 20f 이상 정지, 거리의 70% 를 시간 30% 에 (최고 약 300px/f), 나머지는 긴 ease-out 꼬리(약 48f). 위치는 연속 속도 곡선(3f 가속 + 지수 감쇠)을 적분해서 구하고, 블러는 속도에 비례하는 방향 blur (약 0.085×속도, 최대 64px).
- 함정: whip-pan 최고 속도가 300px/f 에 못 미치면 화면이 바뀌는 게 보인다.
- 원본: `transition/shot-transitions.md` (A · B)

### `hidden-cut`
흐린 전경이 지나가거나 빛이 가장 밝아지는 1~3프레임 안에 컷을 숨긴다.
- 만드는 법: 전경 가림은 가운데 단색 2600px + 양옆 340px 부드러운 그라디언트 판을 14f 동안 `cubic-bezier(0.3,0,0.7,1)`로 지나가게 하고, 화면을 완전히 덮은 프레임에서 장면을 바꾼다. 앞뒤 내용은 +40→−40px 로 계속 천천히 흐른다. 빛샘은 대각선으로 늘린 radial 그라디언트 3개(screen)를 t² 로 밝게 올려 정점에서 컷, 정점에 brightness +85% · contrast −50% (올라가기 28f + 내려가기 43f).
- 함정: 전경 판이 화면을 완전히 덮는 프레임이 실제로 있는지 프레임 단위로 확인. 빛샘은 한 편에 한 번, 흰 번쩍과 같이 쓰지 않는다.
- 원본: `transition/transition-hidden-cut.md` (A · C)

### `push-stack-wipe`
새 장이 배경색째 아래에서 밀고 올라와 옛 장을 위로 밀어낸다.
- 만드는 법: 장 i 의 위치 하나의 식 `y = (1 − 자기 진행)·H − (다음 장 진행)·H`. 곡선 `cubic-bezier(0.12,0.9,0.2,1)`, 26f. 새 장 위 가장자리에 56px 그림자 + 2px 밝은 선. 장 간격 약 44f, 이웃 장끼리 색상을 크게 벌린다.
- 함정: 두 장의 곡선이 조금이라도 다르면 미끄러져 겹쳐 보인다. 장 안 애니메이션은 밀어 넣는 26f 동안 피한다.
- 원본: `transition/bottom-push-stack-wipe.md`

## 마무리

`craft.md` Q8(단체 사진)이 기본이다. 기능 대표 요소를 사방에서 모아 로고를 둘러싸는 장면은 이 목록에 따로 없고, 고른 기법들의 요소 컷아웃으로 직접 만든 뒤 아래 둘 중 하나로 로고를 닫는다.

### `strip-away-outro`
출시 버튼을 누르면 UI 가 바깥부터 층층이 증발하고, 남은 버튼이 가운데로 온 뒤 로고로 넘어간다.
- 만드는 법: 의미 단위 6층을 클릭 +4f 부터 4f 간격으로 지운다 (층마다 14f ease-in, 바깥 방향 50~140px, blur 0→7px). 배경은 +20f 부터 20f 동안 어두운색으로. 버튼은 18f 동안 중앙으로 · ×1.5, 빛번짐 30→70px. +52f 버튼 사라짐 시작, +62f 로고가 스프링(14/90)으로 86→100%.
- 함정: 층을 픽셀 영역으로 자르면 어정쩡한 조각이 남는다. 의미 단위(요소 컷아웃)로. 버튼은 항상 맨 위 z-index.
- 원본: `outro/ui-strip-away-outro.md`

### `logo-lockup`
화면 가득한 고리가 작은 아이콘으로 줄어 멈추고, 아이콘이 옆으로 비키면 글자 로고와 태그라인이 차례로 나온다.
- 만드는 법 (정규화 시간 t): 0.02~0.28 scale 5.4→1 (inOutCubic), 0.26~0.37 sin 곡선으로 6% 넘쳤다 돌아옴. 0.34~0.47 아이콘이 왼쪽으로 비킴 (거리는 전체 로고 폭에서 계산). 글자 i 는 t = 0.46 + i·(0.24/n) 에 시작해 0.10 동안 opacity · x 8→0. 태그라인은 0.72~0.84 한 줄 통째로 페이드인. 끝에서 1초 이상 정지 (R1).
- 함정: 이동 거리가 글자 로고 실측 폭에 묶여 있어 글꼴을 바꾸면 다시 잰다. 로고는 고리와 같이 회전시키지 않는다.
- 원본: `outro/logo-shrink-wordmark-lockup.md`
