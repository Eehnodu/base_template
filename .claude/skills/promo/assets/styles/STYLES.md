# 디자인 스타일 프리셋

색 · 글꼴 · 크기 단계 · 모서리 · 그림자 · 장식 · 해도 되는 것 / 안 되는 것을 한 벌로 묶은 영상용 디자인. `/promo` · `/teaser` 1단계에서 고른다. 프리셋은 **배치의 뼈대**이고, 프로젝트 브랜드 색이 있으면 색은 브랜드로 바뀐다 (`style.mjs use --brand`).

출처: heygen-com/hyperframes `skills/hyperframes-creative/frame-presets` (Apache-2.0) 중 6개. 색 값 · 규칙은 원문을 따르고, 이름 · 설명 · 한글 글꼴 짝 · 본문 대비용 보조 글자색(일부) · 강조 방식(한글은 기울이지 않음)은 우리가 정했다 (변경함). 원문은 움직임을 다루지 않아 프리셋마다 `craft.md` 움직임 성격을 하나씩 붙였다.

## 고르는 법

1. 브리프의 제품 성격으로 2~3개를 고른다 (위 "고를 때 · 피할 때").
2. `node style.mjs showcase <이름들> --brand <브랜드 색>` → `qa/styles.jpg`. 견본 4장면(표지 · 기능 · 숫자 · 마무리)을 사용자에게 보여 주고 고르게 한다. 이름이 아니라 그림으로 고른다. "같이 정하기"가 아니면 스스로 고르고 이유를 `plan.md`에 적는다.
3. 사용자에게 알린다: 견본은 그 프리셋 색이고, 고르는 것은 배치 · 모양이며 색은 브랜드로 바뀐다.
4. 맞는 프리셋이 없으면 쓰지 않는다. 지금처럼 프로젝트 토큰으로 방향을 정한다 (1단계 기본 절차).
5. 같은 프로젝트의 이전 영상이 프리셋을 썼으면 그것을 이어 쓴다 (`plan.md`의 `style`).

## 적용

```bash
node style.mjs use <이름> --brand "<브랜드 색[,둘째 색]>"   # style.css · style.js · style.json, 대비 검사
node style.mjs fonts                                        # 글꼴을 fonts/ 로 (한 번, 프리셋당 수 MB)
node style.mjs use <이름> --brand "..."                     # 글꼴을 받은 뒤 다시 (style.css 가 fonts/fonts.css 를 불러오게)
```

- composition 은 `parts.css` 다음에 `style.css`, `engine.js` 다음에 `style.js`를 불러온다 (틀에 이미 있음). 움직임은 `V.setToken(STYLE.token)`.
- 화면은 `styles/base.css` 클래스로 짠다: `.s-frame`(바탕 · 여백, `data-ground="2"` · `"accent"`로 바탕 바꾸기) `.s-eyebrow` `.s-h1` `.s-h2` `.s-h3` `.s-lead`(읽는 글 66px) `.s-body`(보조 44px) `.s-stat` `.s-card` `.s-pill` `.s-cta` `.s-rule` `.s-deco.*`(장식 — 프리셋마다 모양이 다르고 안 쓰는 건 숨겨짐). 강조 단어는 `<em>` (한글은 기울이지 않는다).
- 실제 화면 캡처(`.card` · `.frame` 안)는 프리셋 색을 입히지 않는다. 틀 · 글자 · 장식만 프리셋을 따른다.

### 브랜드 색 바꾸기 (`--brand`)

- 바꾸는 것은 색 값 · 글꼴 이름뿐이다. 모양 · 규칙은 그대로.
- 프리셋 강조색마다: 색상 · 채도는 가장 가까운 브랜드 색에서, **밝기(휘도)는 원래 색과 같게** — 그래서 원래 프리셋의 대비 관계가 유지된다. 원문은 HSL 명도를 유지했는데, 코발트 → 청록처럼 색상이 바뀌면 같은 명도라도 밝기가 달라 대비가 1.3까지 떨어졌다 (시험에서 확인).
- 회색(채도 0.06 미만) · 상태색(positive · negative)은 바꾸지 않는다. 다크 브랜드 반전은 없다 (6개 모두 밝은 바탕 또는 대자보처럼 원래 어두운 바탕).
- `--ink` · `--canvas`로 글자 · 바탕을 직접 줄 수 있고, `--font-display` · `--font-body`로 한글 글꼴을 브랜드 글꼴로 바꿀 수 있다 (그 글꼴의 `@font-face`는 composition 에서 직접).
- 대비 검사 (WCAG): 글자 / 바탕 4.5 미만, 보조 글자 / 바탕 4.5 미만, 강조 바탕 위 글자 3 미만이면 **실패(exit 1)** — 다른 브랜드 색 · `--ink` · 다른 프리셋으로. 강조색 / 바탕 3 미만은 주의 (그 스타일이 강조색을 글자에 쓰지 않으면 괜찮음 — 블록 팝 · 그림책은 면에만 씀).

## 지킬 것 (스타일별)

**코발트 보고서** — 강조는 한 색만, 제목은 거의 검정(강조색으로 칠하지 않음), 카드는 옅게 물든 면 + 옅은 테두리 · 그림자 없음, 크롬은 알약 모양. 장식(대각 면 · 점 격자)은 표지 · 마무리에만. 둘째 강조색 · 직각 모서리(진행 막대 빼고) · 본문 대문자 금지.

**블록 팝** — 테두리와 그림자는 짝(4px↔8px, 3px↔4px), 그림자는 검정 · 번짐 없음 · 오른쪽 아래. 장면마다 파스텔 바탕을 돌리고 장면마다 장식 하나 이상(기울임 · 별 · 줄무늬 · 점). 둥근 모서리 · 번진 그림자 · 색 테두리 · 여섯째 파스텔 금지. 강조 단어는 형광펜 면으로(파스텔 글자는 안 읽힘).

**빨강 포스터** — 강조는 빨강 하나, 장면마다 큰 글자 하나, 빨강 큰 글자 · 숫자는 −5° 기울이고 겹친 글자 그림자. 카드는 왼쪽 빨강 막대. 둥근 모서리 · 그림자(글자 그림자 빼고) · 둘째 강조색 금지. 한 문장 장면은 여백을 남긴다.

**주황 대자보** — 주황은 검정 위 유일한 강조이거나 화면 전체. 주황 위 글자는 반드시 검정 잉크(크림 글자 금지). 장면마다 주장 하나, 목록은 셋까지, 위계는 굵기 · 크기 · 1px 선으로. 둥근 면 · 그림자 · 그라데이션 · 세리프 금지. (원문의 "영문 제목은 소문자"는 한글에 해당 없음.)

**캔디 캡슐** — 글자 담는 틀은 모두 알약 + 2px 잉크 외곽선, 제목은 잉크색 세리프(칠하지 않음), 색은 숫자 · 알약 채움에만. 그림자는 옅은 오프셋(8% 잉크), 떠 있는 장식 알약은 평평하게. 각진 글자 틀 · 외곽선 없는 알약 · 색 칠한 제목 금지.

**그림책** — 모든 모양에 3px 숯색 외곽선 + 번짐 없는 오프셋 그림자, 둥근 모서리. 채도 높은 바탕 위 제목은 흰 글자 + 숯색 글자 그림자. 산호색은 작은 표시에만(면 금지), 장면마다 큰 틀 하나, 모서리는 장식으로 채운다. 셋째 글꼴 · 색 테두리 · 번진 그림자 금지.

## 공통

- 숫자는 지어내지 않는다. 견본의 숫자는 예시이고, 영상에는 프로젝트에 있는 숫자만.
- 제목이 화면 끝에서 끝까지 차면 한 단계 작은 크기로 (줄 길이 · 여백 유지).
- 렌더 전 자동 검사(`render.mjs`)가 화면 글자 · 면의 색과 글꼴이 프리셋(+ 브랜드 원색) 안에 있는지 본다. 일부러 프리셋 밖 색을 쓰는 요소는 `class="free"`로 표시하고 이유를 `plan.md`에.
