# 하네스 회고 기록

`/retro` 가 쓰고 읽는다. 하네스(`CLAUDE.md` · `.claude/`)를 무엇 때문에 고쳤고, 고친 것이 실제로 도움이 됐는지를 쌓는다. 다음 회고는 아래 "판정"이 `확인 중` 인 행부터 다시 센다 (`.claude/skills/retro/SKILL.md` 0단계).

판정: `확인 중` · `도움` · `해로움` · `효과 없음` · `섞임`. 근거 숫자는 `python .claude/scripts/harvest_sessions.py` 출력 기준이다.

### 교훈

- 상황: 수정 직후 검사 훅이 파일 전체를 다시 훑는다
- 교훈: 훅은 이번 도구 호출이 바꾼 줄만 알린다 (`check_touched_file.py`). 이미 받아들인 예외가 매번 다시 잡히면 같은 경고가 수십 번 쌓여 작업 자리를 먹고, 진짜 새 위반이 묻힌다
- 근거: 수정 1행 — 같은 줄 13번 반복, 주석 오탐 10건
- 확신도: 중간 (기록은 분명하지만 효과는 다음 회고에서 확인)
